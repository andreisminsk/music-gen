Title: Create a new Pod
Link: https://docs.runpod.io/api-reference/pods/POST/pods
Page: api-reference/pods/POST/pods
Content: REST Endpoint POST /pods
Summary: Create a new Pod
Description: Creates a new [Pod](#/components/schemas/Pod) and optionally deploys it. Review parameters and responses for this Runpod API operation in detail.
Request body:
Description: Input for Pod creation.
Content type: application/json
- allowedCudaVersions: type enum<string>[]; description If the created Pod is a GPU Pod, a list of acceptable CUDA versions on the [Pod](#/components/schemas/Pod). If not set, any CUDA version is acceptable.
- allowedCudaVersions[]: type enum<string>; enum 13.0, 12.9, 12.8, 12.7, 12.6, 12.5, 12.4, 12.3, 12.2, 12.1, 12.0, 11.8

- computeType: type enum<string>; description Set to GPU to create a GPU Pod. Set to CPU to create a CPU Pod. If set to CPU, the Pod will not have a GPU attached and properties related to GPUs such as gpuTypeIds will be ignored. If set to GPU, the Pod will have a GPU attached and properties related to CPUs such as cpuFlavorIds will be ignored.; enum GPU, CPU; default GPU
- containerDiskInGb: type integer | null; description The amount of disk space, in gigabytes (GB), to allocate on the container disk for the created Pod. - countryCodes: type string[]; description A list of country codes where the created Pod can be located. If not set, the Pod can be located in any country.

- interruptible: type boolean; description Set to true to create an interruptible or spot Pod. - vcpuCount: type integer; description If the created Pod is a CPU Pod, the number of vCPUs allocated to the Pod.; default 2
- volumeInGb: type integer | null; description The amount of disk space, in gigabytes (GB), to allocate on the Pod volume for the created Pod. - volumeMountPath: type string; description If either a Pod volume or a network volume is attached to a Pod, the absolute path where the network volume will be mounted in the filesystem.; default /workspace
