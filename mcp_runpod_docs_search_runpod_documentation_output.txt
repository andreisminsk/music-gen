Content: Get a GPU type
Retrieve one Runpod GPU type with pricing and optional availability details for a specified product and deployment context.

REST Endpoint GET /v2/catalog/gpus/{id}
Summary: Get a GPU type
Description: Returns a single GPU type with pricing. Availability details are included only when requested with include=AVAILABILITY, which requires `product` â stock differs by product context.
Path parameters:
- id: type string; required
Query parameters:
- include: type enum<string>[]; description Comma-separated optional expansions. Supported value today: AVAILABILITY. This may expand with more include values in the future.
- product: type enum<string>[]; description Comma-separated availability product contexts. Supported values: POD, CLUSTER, SERVERLESS. Required with include=AVAILABILITY, and valid only with it (400 either way). There is no default: the same GPU type can be scarce for pods and plentiful for serverless, so the context has to be stated rather than assumed.
- count: type integer; description GPU count for availability and lowest-price calculations. Valid only with include=AVAILABILITY. Defaults to 1.; default 1
- cloud: type enum<string>; description Cloud type for availability and lowest-price calculations. Valid only with include=AVAILABILITY. Supported values: SECURE, COMMUNITY. Upstream default when omitted: SECURE.; enum SECURE, COMMUNITY
- countryCodes: type string[]; description Comma-separated ISO 3166-1 alpha-2 country codes, uppercase, to constrain availability to â e.g. FR or FR,DE. Values within this filter use OR semantics. Valid only with include=AVAILABILITY (400 otherwise); a malformed entry is a 422. Scopes availability, lowest-price calculations and the dataCenters array to those countries, so a listed data center outside them is omitted rather than returned with availability NONE. On the list endpoint a GPU type with no data center in those countries drops out entirely; the single-GPU endpoint still returns the requested type, with availability NONE and dataCenters omitted, so a 404 keeps meaning the GPU type does not exist. Read the NONE on availability rather than the absence of dataCenters, which is also absent when availability was not requested.
- cudaVersions: type string[]; description Comma-separated CUDA versions to scope availability and lowest-price calculations to, matched exactly. Format: major.minor, e.g. 12.8 â a bare major is rejected here because it identifies no version. Valid only with include=AVAILABILITY (400 otherwise) and mutually exclusive with minCudaVersion (400 if both are sent); a malformed entry is a 422. Also narrows the returned cudaVersions array; omit it to enumerate every version offered.
- minCudaVersion: type string; description Lowest acceptable CUDA version to scope availability and lowest-price calculations to, compared numerically. Format: integer major or major.minor, e.g. 12 or 12.1 â unlike the `gpu.minCudaVersion` body field on pod and endpoint create, a bare major is accepted here and means any release of that major, because this filter only widens a read. Valid only with include=AVAILABILITY (400 otherwise) and mutually exclusive with cudaVersions (400 if both are sent); a malformed value is a 422. Use this for an open-ended floor and cudaVersions for an exact set.
Responses:
200: OK
Content type: application/json
- id: type string; required; description Individual GPU type identifier (use for pod creation)
- name: type string; required
- pool: type string | null; required; description Serverless GPU pool ID (use for serverless endpoint creation). Null if GPU is not in a serverless pool.
- manufacturer: type enum<string>; required; description Canonical GPU hardware manufacturer.; enum NVIDIA, AMD, UNKNOWN
- memory: type integer; required; description VRAM in GB
- secure: type boolean; required; description Available on secure cloud
- community: type boolean; required; description Available on community cloud
- price: type object; required; description List price in USD per hour for a **single** GPU of this type. Pod
rates are quoted separately per cloud (`secure`, `community`);
`serverless` is the rate for this GPU's pool. In every case the
rate for a unit is the figure times `gpu.count`; the rate actually
billed for a pod is reported as `cost` on the pod itself.

- price.secure: type number<float>; required
- price.community: type number<float>; required
- price.serverless: type number<float>; description Serverless list price per GPU per hour, from the `pool` this GPU
belongs to. Multiply by `gpu.count` for the per-worker rate.
Absent when the GPU is not in a serverless pool available to the
caller. Negotiated account discounts are not reflected.

- maxCount: type object; required; description The largest number of GPUs you can request on a single pod of this
type, quoted separately per cloud. A pod runs on one machine, so
this is the GPU count of the largest machine of this type Runpod
operates in that cloud.

This is a ceiling, not a stock level â it does not mean that many
GPUs are free right now. For current availability, request
`include=AVAILABILITY&product=POD` and read `availability`
(overall) or `dataCenters` (per data center).

- maxCount.secure: type integer; required
- maxCount.community: type integer; required
- availability: type enum<string>; description Overall GPU availability for the requested `product` contexts. Present only when requested with include=AVAILABILITY, which also requires `product`.; enum NONE, LOW, MEDIUM, HIGH
- dataCenters: type object[]; description Per-datacenter GPU availability for the requested `product`
contexts, listing only the datacenters that offer this GPU in the
requested configuration. Present only when requested with
include=AVAILABILITY, which also requires `product`, and omitted
entirely when the configuration is unavailable everywhere.

- dataCenters[]: type object
- dataCenters[].id: type string; required; description Data center identifier.
- dataCenters[].name: type string; required; description Human-readable data center name.
- dataCenters[].availability: type enum<string>; required; description Catalog stock availability level.; enum NONE, LOW, MEDIUM, HIGH
- cudaVersions: type object[]; description CUDA versions offered by machines with this GPU type, each tagged
with current capacity. Present only when requested with
include=AVAILABILITY, and scoped by the same filters as
`availability` (`count`, `cloud`, `product`, and whichever of
`cudaVersions` / `minCudaVersion` was supplied).

Machines that report no CUDA version are skipped, so this property
is absent entirely for a GPU type with none â AMD, for instance.
Treat a missing `cudaVersions` the same as an empty one. A version
absent from a populated list is not offered for this GPU type.

- cudaVersions[]: type object
- cudaVersions[].version: type string; required; description CUDA version as `major.minor`, suitable for `gpu.allowedCudaVersions` on pod create.
- cudaVersions[].available: type boolean; required; description True when at least one machine on this CUDA version has free capacity now. False means the version is offered for this GPU type but is currently full, so a pod constrained to it will fail on capacity.
